Aplomb · 从容
=============

一个只做一件事的 Windows 小工具：让窗口回到它该在的位置。


默认快捷键
----------
    Ctrl + Alt + C    居中当前窗口
    Ctrl + Alt + X    选择窗口居中（弹出缩略图浮层）
    Ctrl + Alt + B    全部窗口居中

    可以在「设置 → 快捷键」里改，改完立即生效。


怎么用
------
程序启动后常驻系统托盘，不占任务栏。

    左键单击托盘图标    打开设置
    右键单击托盘图标    菜单（设置 / 开机自启 / 退出）

选择器浮层里：

    直接打字      按标题或进程名过滤
    方向键        移动选中
    Enter         居中
    Esc           取消并退回原来的窗口
    Ctrl + 点击   多选


配置在哪
--------
    %APPDATA%\Aplomb\config.json

卸载不会删除这个文件，重装后设置还在。


卸载
----
开始菜单 → Aplomb → 卸载 Aplomb
或者：设置 → 应用 → 安装的应用 → Aplomb
